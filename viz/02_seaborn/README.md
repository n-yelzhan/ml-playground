\# Seaborn basics — Penguins

Goal: explore how three penguin species differ by body measurements using seaborn (histplot, boxplot, pairplot, heatmap).

Model: no model — exploratory data analysis on the seaborn Penguins dataset (rows with missing values dropped).

Result: Gentoo separates by flipper length alone; Adelie vs Chinstrap separate only with bill length + bill depth together. Bill depth vs body mass: -0.47 across all species, +0.72 inside Gentoo.

Key takeaway: one feature rarely separates segments, a pair often does; and correlations on mixed groups can flip sign (Simpson's paradox).
