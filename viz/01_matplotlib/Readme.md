\# Matplotlib basics — Tips

Goal: learn the four basic chart types in matplotlib (histogram, bar, line, scatter) using the Figure/Axes approach.

Model: no model — exploratory charts on the seaborn Tips dataset.

Result: tips grow with the bill; in dollars Sunday has the highest average tip, but in % of the bill Friday leads and the gap between days is under 2 p.p.

Key takeaway: the choice of metric and scale can change the conclusion — compare relative metrics (%), not only absolute ones ($).
